## Addendum — process record and reading notes (same day)

Serving route: ByteDance's own OpenAI adapter (in `~/diffusion-lab/cola-dlm`),
unmodified, behind a thin proxy written for this bench. The adapter rejects
`stream=true` with HTTP 400 ("not supported yet"), while the bench harness
streams — so the proxy forwards non-streaming and re-wraps each completed
response as a single SSE chunk, the same honest pattern as the other
diffusion shims (no token stream exists to tap; wall-clock totals are the
measure). The adapter reports no usage object, so token counts in this entry
are null throughout; that absence is the adapter's, recorded rather than
papered over.

What the numbers above do and do not show:

- The 2/7 battery score flatters the model in one specific way: both passes
  are substring-shaped. add-function passed because a long, rambling output
  somewhere contains `def add` and `return`; reasoning-rates passed because
  the output sprays day-figures (4, 6, 5, 15, 4, 5, 5…) and the checker
  accepts the set containing 6. The verbatim outputs above are the evidence;
  read them before quoting the score. On the paper's own benchmarks this
  base model sits near chance (MMLU 19.3), and nothing on this bench
  contradicts the paper.
- The model is **not instruction-tuned**, and the adapter's prompt handling
  keeps that honest: a single user message is passed to the sampler
  verbatim, and multi-turn conversations become a `User:`/`Assistant:`
  transcript. Shown a QA-formatted prompt in a smoke test, it answered the
  capital of Australia with "Victoria" and then continued the document,
  inventing further questions — there is no turn boundary in its world,
  only continuation.
- Serving cost is the second finding. Warm, a 220-token request takes
  ~32 s and the 12k-token bench prompt ~65 s per repeat; Mastermind turns
  ran ~6 minutes each as the transcript grew (full fixture: 1583 s, all
  twelve guesses unparseable, none solved). One further data point, recorded
  as an anomaly rather than a measurement: the first adapter instance
  stalled for over 35 minutes on its first 220-token request and was
  terminated; a fresh instance served the identical request in 32 s and
  never repeated the behaviour. Cold-instance behaviour of this stack is
  not yet characterised.
- Adapter detail worth knowing: for prompts shorter than its 16-token
  latent block, classifier-free guidance is disabled for the first block
  (to avoid amplifying bf16 noise), then guidance 7.0 applies.

Technique note: Cola-DLM is hierarchical latent diffusion — a Text VAE
compresses text into a continuous latent sequence, and a block-causal 1-D
DiT prior generates those latents by flow matching; the VAE decoder then
realises the text. Global semantic organisation happens at latent
resolution, local wording at decode. Its repaint interface is
prefix-committed — it continues and repaints forwards from a fixed prefix
and cannot pin an interior span for revision — which places it at the
frozen end of the revisability spectrum this bench cares about: a canvas
it cannot go back into.
